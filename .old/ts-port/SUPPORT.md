# Support

ace is an early open-source project. The fastest way to get useful help is to keep reports focused and include enough context for maintainers to reproduce or reason about the issue.

## Where To Ask

- Bugs and regressions: open a bug report issue.
- Feature requests: open a feature request issue after checking for duplicates.
- Usage questions and troubleshooting: use GitHub Discussions when enabled.
- Security issues: report privately through GitHub Security Advisories.

## What To Include

- ace version or commit.
- Operating system and install method.
- Provider CLI involved, if any.
- Exact command or workflow that failed.
- Relevant logs with secrets, tokens, local paths, and private repo data redacted.
- Screenshots or recordings for visible UI issues.

## Response Expectations

Maintainers prioritize security, data loss, session/runtime reliability, release regressions, and reproducible cross-platform issues. Non-reproducible reports may be closed with a request for more information.

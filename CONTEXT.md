# ace

ace connects a person's clients to coding agents running on their own machines.

## Language

**ace account**: The person's identity in ace. Signing in is optional for local use.

**Provider account**: A coding-provider login available on a machine. It is independent of the person's ace account.

**Paired-device grant**: A machine owner's authorization for a particular device to access that machine with specific scopes. An ace account alone grants no machine access.

# 0230: Give the person's iPhone transcript bubbles the accent

Status: Accepted. Date: 2026-11-25. The owner approved the change after reviewing an iPhone thread.

## Context

The owner found the person's dark grey bubbles too close to the agent's prose and the conversation too cramped. The agent's paragraphs, work summary and reply had nearly the same gaps.

## Decision

- Use the same accent, paired on-accent ink and bubble shape for the person's messages in iPhone threads and Spade. Keep briefs sent by other threads on the neutral fill.
- Give the person's messages and the start of an agent reply 24 points of room at standard density. Keep 14 points between other rows and use 12 points between paragraphs and list items in agent replies. The answer role uses 17-point type with 25-point lines. Use muted ink for the collapsed work summary.

# Computer-use action overhead

Measured 2026-10-23 on macOS 26.2. Baseline is the signed helper built from
`3367e1d6b`; its cached source fingerprint was verified against that commit before
copying the bundle. The updated helper uses the same signing identity. These are
local helper/toolkit measurements, excluding model inference and network latency.

## Changes

- Human-conflict queries run only for recent human input in the unlocked, frontmost
  target app. Background and idle actions avoid the focus, ancestry and pointer reads.
  Cancellation, Esc and session-availability checks retain their priority.
- Direct AX value, selection and focus actions skip background key-window activation.
  Posted typing, keys, paste and menu commands retain their existing routing.
- Explicit `wait`/`wait_for` steps own their synchronization, avoiding an additional
  settle immediately before them. A conditionally skipped step adds no settle. Guards
  on the following step, navigation, submission and ordinary dependent actions retain
  their existing settling. Final observed results still settle.
- Optional diagnostics report queue, startup, helper round trip, decode and total
  request durations, plus native action, guard, settle, walk and screenshot phases.

## Results

| Scenario                                                                        | Before warm median | After warm median |
| ------------------------------------------------------------------------------- | -----------------: | ----------------: |
| Calculator Escape followed by `wait_for` the zero display, no final observation |             196 ms |             91 ms |
| Owned background text fixture, 20 semantic actions                              |           130.4 ms |           95.5 ms |
| Calculator observed button press                                                |             102 ms |            103 ms |
| Calculator button press without observation                                     |               8 ms |              7 ms |

The Calculator benchmark uses eight warm rounds after one cold round. The fixture
uses five warm rounds after one cold round. Each fixture batch repeats focus, set
value, select text and set value five times. Every batch completed all twenty steps;
a separate observation verified the final text and that the app remained inactive.
The fixture contains only disposable text and was closed after validation.

The Calculator comparison ran on a busy Mac with different load averages, 13.45
before and 26.18 after. Results establish gains for the measured paths, not a general
speedup across apps. Screenshot timings varied and are not claimed as an improvement.
No incremental tree/search, screenshot-encoding or general keyboard-delay changes
are included in this revision.

Raw per-sample results are not kept in the repository; rerun the benchmarks below to
reproduce them.

## Diagnostics and reproduction

Set `ACE_CU_TIMINGS=1` when starting the daemon to emit duration-only computer-use
records on daemon stderr and request native helper timings. Records include the op,
app identifier and outcome, but omit action arguments, window titles, document text
and screenshots. Diagnostics are off by default. A throwing diagnostic consumer
cannot fail an action or strand the next queued request.

`startupMs` includes helper resolution/installation and process creation until the
request is sent. `helperMs` includes transport, native execution and reply writing;
it is not a pure CPU measurement. Native `guardMs` is a subset of `actionMs`, and
observation subphases overlap the enclosing `observationMs`. Do not sum these nested
durations. Registry formatting, model inference and network latency require their
own outer measurement.

```sh
ACE_CU_TIMINGS=1 ACE_COMPUTER_HELPER="$PWD/native/screen-helper/build/ace-screen-helper" node packages/screen/bench/computer-actions.ts 8
```

This command operates Calculator and requires existing OS permissions. The report
includes the outer toolkit latency and per-request phase durations. It separates
cold requests from subsequent rounds.

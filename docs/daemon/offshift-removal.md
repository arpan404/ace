# Offshift removal (2026-10-07)

Offshift, previously Deck, and its native conductor are removed. Use ace's agent
orchestration and `delegate_task` for coordinated work. ADRs 0017 and 0060 remain
historical records marked removed. Agent trees, delegation, automations, threads,
worktrees, git integration, review and forge operations retain their shared owners.

## Stored data

A versioned migration drops only the event database's conductor execution roots,
lanes, gate bindings, command attempts and workspace Deck ownership tables. It
removes obsolete Deck display metadata from thread client fields. Thread and agent
records, titles, transcripts, queue/recovery state, shared approvals, delegation
edges and ordinary workspaces remain. Historical event payloads remain raw history.

The separate `conductor.sqlite` database is left untouched and inert. Nothing opens
it after upgrade. Keeping this archive avoids deleting the old run/artifact history;
no runtime, protocol or client API can execute those runs. Old `conductor.*` settings
are preserved as unknown document keys and have no effect.

Cold engine recovery cancels pending `ace.conductor.gate` interactions, whose owner
no longer exists. Ordinary provider and browser interactions follow their existing
recovery rules; for example, browser recovery expires its own orphaned approvals.
Live lane sessions follow ordinary restart recovery, retaining their native session
identity. A missing workspace uses global/thread recovery settings with automatic
continuation disabled, so a removed checkout cannot crash startup or run implicitly.
Restore or select an existing checkout before continuing such a thread.

## Worktrees

On the first successful upgrade pass, the daemon scans only its `deck-worktrees`
directory. The existing GitService removes clean registered worktrees without
force. Dirty, staged, untracked, ignored, hidden-index, locked, quarantined or unreadable
worktrees remain, and the daemon logs their paths. Symlinks are never followed.
Branches are retained. The scan records completion in the event database; later
starts do not delete worktrees that were retained on upgrade and later became clean.
An interrupted pass can retry safely. No other worktree directory is scanned.

The shared GitService integration API retains its historical
`refs/ace/conductor/<key>` receipt namespace for replay compatibility. These refs
are immutable merge receipts, not an active conductor or scheduler.

## Clients

Conductor commands, requests, events, schemas and client helpers are removed.
Older wire messages receive the existing `invalid_message` error without closing
the connection. `/deck`, `/offsets`, `/offshifts` and their nested paths redirect to
Home. The sidebar, launcher, menus, shortcuts and Activity show ordinary threads,
agent orchestration and automations.

The upgrade regression uses compressed databases generated by the actual
`origin/main` schema and public engine/conductor APIs, with a live scripted lane.
It operates only on extracted copies and temporary repositories. No live ace home
or provider CLI is used.

# Server results and push messages

Generated by `bun run docs:protocol`. Edit source schemas, then regenerate.

JSON Schema validates structure. `x-ace-constraint` names additional semantic rules that clients must enforce; Zod remains the full validator.

`welcome` establishes protocolVersion and headSeq. Snapshot seq must match view.seq. Events and progress advance coverage even for filtered subscriptions. `firstSeq` describes coalesced delta coverage. Persist throughSeq only after applying a batch. Errors include a code and message; `pong` answers `ping`. Notifications grant no approval authority.

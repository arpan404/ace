# Commands

Generated by `bun run docs:protocol`. Edit source schemas, then regenerate.

JSON Schema validates structure. `x-ace-constraint` names additional semantic rules that clients must enforce; Zod remains the full validator.

Send commands inside the client `command` envelope. Retry with the same command id for idempotency. The daemon replies with `commandResult`, whose commandId correlates with the request. `ok: false` and `error` describe rejection; acceptance does not mean the whole agent tree has finished.

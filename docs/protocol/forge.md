# Forge

Generated by `bun run docs:protocol`. Edit source schemas, then regenerate.

JSON Schema validates structure. `x-ace-constraint` names additional semantic rules that clients must enforce; Zod remains the full validator.

See [ADR 0016](../adr/0016-forge.md). These contracts come from the public @ace/protocol/forge entry point. Commands, events and PR summaries are service integration contracts; they do not add variants to the daemon's current WebSocket union. Forge facts do not determine agent completion.

| Field | Required | Type | Constraints |
| --- | --- | --- | --- |
| threadId | yes | string | {"minLength":1,"maxLength":256} |
| pr | yes | [ForgePrRef.json](schema/ForgePrRef.json) |  |

Example:

```json
{
  "pr": {
    "number": 3,
    "repository": {
      "forge": "gitlab",
      "host": "5-42F0",
      "name": "JOHoAhXgLt",
      "owner": "hDN2/87d76Dom/vcRCsgp"
    }
  },
  "threadId": "example"
}
```

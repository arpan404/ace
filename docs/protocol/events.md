# Canonical events

Generated by `bun run docs:protocol`. Edit source schemas, then regenerate.

JSON Schema validates structure. `x-ace-constraint` names additional semantic rules that clients must enforce; Zod remains the full validator.

See [ADR 0004](../adr/0004-canonical-agent-model.md). Events are canonical facts, not raw provider frames. Host seq increases across the append-only log. Thread status comes from the whole agent tree: do not infer done from run.ended. Concatenate item.delta; item.updated is authoritative. Items can arrive after their run ends.

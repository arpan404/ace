## Static review

The native executor uses DelegationService admission, engine whole-thread status and recovery. Host reservation ownership is persisted before filesystem preparation. Launch and integration receipts survive retry. Observations are fenced by lane generation and terminal status. Reconciliation is serialized per run and shutdown awaits its I/O before closing storage. Indexed discovery includes nonterminal runs with empty outboxes. The event path coalesces transcript deltas; observations visit bounded live lane bindings rather than plan/history size. These are code-review findings; their execution behaviour needs run at merge.

GitHub publication lookup follows the primary [pull request list API](https://docs.github.com/en/rest/pulls/pulls#list-pull-requests), filtering the exact owner/branch and base and retaining closed identities to prevent duplicate publication after recovery.

## Performance bounds

No benchmarks were executed. Throughput, latency and RSS **need run at merge**; there are no measured benchmark numbers to report under the owner's rule.

Numeric bounds from code: artifact input is at most 1,049,600 UTF-8 bytes (one MiB plus one KiB for its envelope); source reads total at most 2,099,200 UTF-16 bytes in ranges of at most 262,144 bytes. A single contiguous maximum source therefore takes at most nine range reads; multipart messages may need one final range per part. Plan/review compact JSON limits remain 1 MiB/64 KiB. Delta observation loads no transcript and touches one bounded owner/activity cache entry. Each owner cache and activity map holds at most 128 entries. Reconciliation visits current live lanes; wire decoration returns at most 256 delegation records. Command attempt lookup and engine execution lookup use primary/unique keys, retaining one current attempt row per operation rather than scanning retry history.

The numeric limits are static evidence, not throughput/RSS measurements. Artifact assembly/parsing costs O(artifact bytes), once per terminal observation attempt. Run reconciliation and decoration retain their existing bounded lane/edge scans.

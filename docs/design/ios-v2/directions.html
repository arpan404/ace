What it is

Web parity
Inbox · Snoozed · Settled, row actions, multi-select, project filter in the title menu.

Search replaces More

What it is
The tab bar's search becomes the way to everything that isn't a thread. Empty, it shows Places (Pull requests, Automations, Skills, Usage, Fleet, Settings). Typed, it finds threads, PRs, files, settings and actions.
Web parity
Command palette, search, every page under the web rail.

My pick: one app built from six of these

  • Tabs Threads (1) · Chats · Search (10), plus compose (7)
  • Thread pages (4) with Agents as a page (5) and the review sheet when it finishes (6)
  • Outside the app Live Activity, actionable notifications and a widget (8)
  • Folded in needs-you run from the inbox header (2), drawing in the Browser page (9), drawer on iPad only (3)

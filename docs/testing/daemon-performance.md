Static review checked worker admission before sending, generation guards during retirement, reserved close messages, auxiliary executor/import transaction ownership, in-memory database lifetime, queue byte release on all failure paths, unchanged SQLite durability modes, indexed history reconciliation, directory identity and reference ownership in shared settings watches, and bounded weak event encoding. It also checked the merged #82 workspace fences and history progress reporting. #83 is also merged; its Deck workspace migration is preserved before the existing reservation initialization. #84 remains separate; no permission wiring refactor is included here.

The default notifications worker remains resident because it owns live presence, pending aggregation and transport acknowledgements. Reaping it without moving that state would change delivery semantics. Search retains two independently admitted lanes so transcript ranking cannot starve the palette. Different SQLite owners retain their databases and protocols; consolidation into one shared database/pool would require migration and durability design beyond this focused change.

Remaining verification: run the behaviour tests once at merge, run the packaged history import and Claude fork paths, exercise slow-client delivery with several subscribers, check watcher fallback and overflow on Linux as well as macOS, and calibrate the performance gate on CI. `check:deps` passes with an existing dependency-cruiser warning that TypeScript 7 is outside its supported compiler range; that limits its coverage.

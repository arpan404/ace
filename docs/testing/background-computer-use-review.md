## Other review items

- App focus resolution now reads AX focus/bounds once, then scans candidates once. At 128 candidates, the bounds-query algorithm falls from a worst-case 16,384 candidate queries to at most 128, plus one AX focus lookup. These are static operation counts, not measured benchmark results.
- `ScreenManager` now composes capture lifetimes, app launches, access policy, controller leases, observations, recording and action execution. Modules own responsibilities rather than arbitrary pieces of one class. Clocks, process spawners, IDs and schedulers remain injected at I/O boundaries.
- Screen approval deadlines require an injected scheduler; the service supplies Node timers. SQLite behavior cases cover deadline expiry/late replies and grants belonging to another thread.
- Secure fake-helper destinations stay redacted but publish a nonsecret “Changes” observation: denied actions leave it zero, consent permits one effect, and redelegation after takeover refuses further typing. Unicode, named key, scroll and pointer cases assert specific destination values rather than a total action count.
- Native tests assert focus restoration and clipboard content effects, including multiple pasteboard representations and concurrent human copying. Posting and launch tests inject I/O and assert selected process, Unicode payload and preserved human focus. Observation tests assert a changed UI becomes visible after notifications settle.
- The two `setImmediate` drains are removed. Capture release uses the existing public `targets()` transition barrier; failed-process cleanup uses its explicit process-stop acknowledgement.
- SwiftPM excludes the generated `build` directory only when it exists, removing both missing-exclusion and unhandled-build-artifact warnings.
- Main's streaming changes are preserved: H.264, still-image requests, continuous pointer release and 60 fps macOS settings. Native JPEG/video packets carry the session into the shared writer; fake codec/pointer state is per-session. Pointer cleanup preserves the original press mode so a foreground HID press is released through HID at the current cursor position after consent is reset; background cleanup remains process-targeted.
- `@ace/client/screen` provides typed one-shot controls and state notifications. UI work is documented for the Claude web agent; no UI source is changed against main.

# Spade's connector registrations

Generated by `bun run docs:connectors` from [`registry.json`](../../tools/connector-registrations/registry.json). Don't edit this file by hand: change the registry and run the command again. `bun run docs:connectors --check` fails when the registry and the code disagree, or when this file is stale.

Every OAuth app and MCP client approval Spade needs from a maker, in the order to do them: the longest review queues first. Why each one is needed is in [connector-apps.md](connector-apps.md).

The privacy and terms URLs every form asks for, https://acehq.dev/privacy and https://acehq.dev/terms, reach the legal pages through `apps/marketing/public/_redirects`; the check fails if they stop doing so.

## What can be automated

Slack can: `bun run docs:connectors slack --yes` creates the app from its manifest through Slack's `apps.manifest.create` API and prints the client ID and secret once, to the terminal. No other maker here offers an API for creating an OAuth app, so the browser part is done by a person; this page and the runbook (`bun run docs:connectors` writes it to `tools/connector-registrations/out/runbook.html`) put every value one copy away.

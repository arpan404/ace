# Licenses

The Spade Agent Format has two licenses, by kind of file:

- **The spec's text**, every Markdown file in this folder outside `conformance/`, is licensed
  under the Creative Commons Attribution 4.0 International license (CC BY 4.0,
  <https://creativecommons.org/licenses/by/4.0/legalcode>). Each part names it in its header
  (`SPDX-License-Identifier: CC-BY-4.0`).
- **The schemas and the conformance suite**, every file under `conformance/` and every JSON
  Schema the spec publishes, are licensed under the Apache License, Version 2.0, like the rest of
  this repository (the `LICENSE` file at its root). Each case file names it in its `license`
  field.

Anyone may implement the spec without asking. An implementation may say it "conforms to Spade
Agent Format 1.0 at the Reader, Runtime or Surfaces level" when the conformance suite passes at
that level for that version. Neither license grants the Spade name or mark, which stay ace's.
